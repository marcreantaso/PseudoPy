🧪 Compiler Metrics & Evaluation

            
Automated evaluation of the pseudocode-to-Python compiler using the built-in dataset of ground-truth test
              cases. Measures accuracy (exact-match), precision & recall
              (line-level overlap), compilation success rate, runtime error rate, and
              pipeline stage timing. Session metrics update live as you translate; click Run
                Benchmark to evaluate the full dataset.
            

          

          
        


        
        

          ℹ️
          

            How to use this page:

            Session Metrics track live activity from your current session (translations &
            executions done via the Generate Python Code page).

            Benchmark runs all test cases from dataset.json against the compiler and
            computes Accuracy, Precision, Recall, F1 Score, and Compilation Rate.

            Concept Mastery groups benchmark results by programming concept so you can see where the
            compiler performs best and worst.
