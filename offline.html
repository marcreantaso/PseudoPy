Scope and limitations

This is a deterministic rule-based translator, not a neural Transformer. Levenshtein suggestions flag keyword typos; they do not silently repair answers. Manual text, TXT/pseudocode files, and guided examples are supported here. PDF/DOCX extraction is not yet implemented in this offline lab.

AST validation cannot prove arbitrary correctness, termination, or optimal efficiency. No complex libraries, file I/O, OOP, or unrestricted natural-language interpretation. Skulpt is a browser Python subset with execution time and output limits.
