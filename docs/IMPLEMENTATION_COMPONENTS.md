## Thesis claim audit

_The manuscript makes these architectural claims. This table records what
the code actually shows. A claim is "Verified" only when the evidence is
observable without a browser; otherwise it is "Qualified"._

| Claim | Status | Evidence |
|---|---|---|
| Translation and semantic checks run in the browser | Verified | mapper.js + compiler.js compile with no network call; compiler tests run them in a bare VM. |
| Python executes in the browser | Verified | Vendored Skulpt (vendor/skulpt) is precached by sw.js and driven by src/app/execution.js. |
| No backend server is needed to use the client | Qualified | server.js starts Express and api/ adds Vercel handlers sharing an in-memory store. A static host can serve the client, and the inspected client workflows do not call those routes, but cloud sync still needs Firebase. |
| Data is stored in Firebase Firestore | Qualified | src/database/ writes localStorage and IndexedDB first, then syncs to Firestore; offline writes are queued, not lost. |
